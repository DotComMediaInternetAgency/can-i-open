### Separate app claims from current defaults

An app's declared document types show what it says it can handle, not which types currently open with it. For app-to-app reassignment, start from the intersection of the source app's claims and its current editor/viewer defaults. Preselect target-supported types, label unsupported types, and require explicit review before including those unsupported types. Recheck source ownership immediately before applying to avoid stale UI state.
